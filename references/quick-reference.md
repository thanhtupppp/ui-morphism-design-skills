# Quick Reference

| Style | Best use | Main risk | Default stance |
|---|---|---|---|
| Skeuomorphism | Device controls, media, familiar physical tools | Texture and visual weight | Use selectively |
| Flat Design | SaaS, CRUD, dense dashboards | Weak hierarchy | Safe default |
| Neumorphism | Small controls, thermostat widgets | Low contrast | Never alone for complex forms |
| Material Design | Cross-platform systems | Framework defaults | Strong foundation |
| Glassmorphism | Overlays, hero cards, navigation | Contrast and blur cost | Use bounded surfaces |
| Claymorphism | Education, onboarding, gamification | Excessive softness | Use expressive surfaces |
| Liquid Glass | Navigation and contextual controls | Distraction and transparency | Functional material only |
| Aurora UI | Premium AI and marketing surfaces | Visual noise | Background/accent only |
| Bento UI | Product pages and dashboards | Card fragmentation | Layout system, not material |
| Neobrutalism | Bold brands and dev tools | Harsh hierarchy | Deliberate contrast |
| Swiss Editorial | Journals, research libraries, cultural portfolios | Oversized type and broken reading order | Typography and content first |
