# UI Morphism Design Intelligence

This repository is a reusable frontend design skill for selecting and implementing UI morphism styles in production products.

## Code-first usage

Every style directory contains:

- `SKILL.md`: when to use, visual system, risks, accessibility, and anti-patterns.
- `example.css` and `example.tsx`: a runnable starter component.
- `components.md`: component-level recipes for buttons, cards, inputs, navigation, opacity, blur, shadows, radius, borders, states, and responsive behavior.

An agent must read all three files before implementing a selected style. Do not output only generic visual advice; use the concrete recipes and adapt their tokens to the project.
