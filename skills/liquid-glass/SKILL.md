# Liquid Glass / Liquid UI

## Dùng khi
- Hero, media control, experience thương hiệu cao cấp, UI ít dữ liệu.

## Quy tắc
- Base UI dùng được khi tắt effect.
- Animate ưu tiên transform và opacity.
- Không đặt text quan trọng lên phản xạ chuyển động.

## Checklist
- [ ] Có `prefers-reduced-motion`
- [ ] Có fallback filter/mask
